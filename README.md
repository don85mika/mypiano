# MyPiano

Веб-приложение для обучения игре на пианино (в духе Simply Piano / flowkey) под Roland FP-30X.
Один файл `index.html`, без сервера и без зависимостей. Работает в Google Chrome на Android и macOS
(Web MIDI; Safari не поддерживает MIDI).

## Что внутри
- **Путь** — 9 шагов от нуля до своей пьесы, счётчик минут и дней подряд.
- **Пьесы** — встроенные: упражнение «Пять пальцев», «Ода к радости», Бах BWV 846 (такты 1–4).
  Импорт своих пьес: `.mid`, `.midi`, `.musicxml`, `.xml`, `.mxl`. Хранятся в браузере (localStorage).
- **Практика** — режимы «Ожидание» (ждёт правильную ноту), «В темпе» (оценка попадания и ритма), «Слушать»;
  по одной руке или двумя, темп 25–120 %, повтор тактов, аккомпанемент другой руки, метроном,
  названия нот, итог с проблемными тактами.
- **Слух** — «Найди ноту» (подсказки выше/ниже) и «Повтори фразу» (фразы из выбранной пьесы, растут по длине).
- **Ноты** — тренажёр чтения нот в скрипичном и басовом ключе, слабые ноты выпадают чаще.
- **Свободно** — показывает сыгранные ноты на нотоносце и название аккорда.

## Подключение FP-30X
USB-кабель (порт USB COMPUTER, тип B) — самый надёжный. Bluetooth: на Mac через «Настройка Audio-MIDI → Студия MIDI»,
на Android через приложение «MIDI BLE Connect», затем перезагрузить страницу.
Без пианино: клавиши компьютера (A S D F G H J K, W E T Y U; Z/X — октава) или касания экрана; микрофон — запасной режим, одна нота за раз.

## Vladimir's Blues
Пьеса Макса Рихтера защищена авторским правом и не встроена. Файл MusicXML/MIDI пользователь добавляет сам (раздел «Пьесы»).

## Публикация
Для установки на телефон как приложение нужен HTTPS-хостинг (например, GitHub Pages): в папке уже есть
`manifest.webmanifest`, `sw.js` (офлайн-кэш) и иконки.
